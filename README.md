# PL SET

스타크래프트 프로리그 진행자를 위한 방송 콘솔. React + TypeScript로 구현했습니다.

https://starjoa.kr/proleague 에서 설치 없이 브라우저로 사용합니다. PL SET은 웹 버전으로 운영하며, 기존 Windows 설치본(Electron)은 웹 버전이 안정되면 배포를 종료합니다.

## 공정성

핀볼·룰렛·레이스 추첨 결과는 아래 구조로만 정해지며, 진행자가 결과를 지정하거나 바꾸는 기능은 없습니다. 이 저장소의 코드가 웹 버전과 설치본에 그대로 빌드됩니다.

1. 추첨 시작 버튼을 누르는 순간 `crypto.getRandomValues`(브라우저 암호학적 난수)로 32비트 시드 하나를 뽑습니다. `src/domain.ts`의 `randomSeed`.
2. 출발 배치, 룰렛 정지 위치, 물리 시뮬레이션 전체가 이 시드 하나에서 파생됩니다. 코드 어디에도 `Math.random`이나 진행자 입력이 섞이지 않습니다. `src/domain.ts`의 `seeded`, `shuffle`.
3. 결과에 영향을 주는 진행자 설정은 모두 시작 전에 화면에 보입니다: 참가 대상, 선수당 구슬 개수, 코스, 당첨 순위(첫 번째/마지막). 시작 후에는 배속과 카메라만 바꿀 수 있고, 이는 결과를 바꾸지 않습니다.
4. 시드는 외부로 전송되지 않습니다. 웹 버전은 서버 없이 진행자 브라우저 안에서만 동작합니다.

직접 확인하려면 `src/domain.ts`, `src/pinball.ts`, `src/race.ts`, `src/raceWorld.ts`, `src/RoulettePage.tsx`를 읽거나 `src` 폴더에서 `Math.random`을 검색해 보세요. 결과가 없어야 합니다.

## 웹 버전

https://starjoa.kr/proleague 에서 **웹 콘솔 열기**를 누르면 새 창으로 열립니다. 서버 없이 브라우저 안에서만 동작하며, 열 때마다 최신 버전이 적용됩니다.

- 송출: 콘솔을 별도 창으로 띄우고 OBS **창 캡처**로 잡으세요. 탭이 다른 창에 완전히 가려지면 브라우저가 레이스·핀볼 애니메이션을 멈출 수 있습니다.
- 백업: 세션은 이 브라우저에만 저장됩니다. 상단 경기 인원 표시를 눌러 연 경기 설정에서 **세션 내보내기**로 JSON 백업을 남기고, 다른 PC나 브라우저에서는 같은 곳의 불러오기로 옮깁니다.
- 배포: `npm run build:web`이 `/proleague/app/` 기준 경로로 빌드해 스타조아 저장소의 `public/proleague/app`에 복사하고, 스타조아를 배포하면 반영됩니다.

## 사용법

1. 대시보드 맨 위 **참가자 입력칸**에 선수 이름이나 별명을 입력하고 Enter를 누릅니다. 선수의 실제 종족에 따라 T / Z / P 줄로 자동 배치됩니다. `재호 김정우 현제`처럼 여러 종족 선수를 한 번에 입력할 수 있고, `현제`를 입력하면 변현제의 사진이 검색 결과에 나타납니다. **선수 목록**이나 **참가자 관리**에서도 이름·별명·초성으로 선택할 수 있습니다.
2. **진행 대시보드**는 두당 금액 입력이 기본입니다. 필요하면 후원 총액으로 전환할 수 있습니다. Enter 또는 입력칸 밖 클릭으로 확정하고 Escape로 입력을 취소합니다. 금액이 확정되면 펀딩 높은 순으로 자동 정렬됩니다. 두당·토탈 펀딩 합계는 표 오른쪽에 세로로 표시됩니다. 참가자에서 제외한 선수는 펀딩 목록에서도 즉시 사라집니다.
3. **팀 편성**에서 A/B 버튼 또는 드래그로 배정하거나 무작위로 두 팀을 만듭니다.
4. **레이스**는 참가자(전체·A팀·B팀·직접 입력, 최대 30명)를 내리막 트랙 6종에서 달리게 해 첫 완주자를 뽑습니다. 정글·은하수·설산·도심·화산·협곡 중 선택하며, 협곡은 약 1.06km의 긴 지그재그와 좌우 스윙 바를 갖춘 코스입니다. 모든 맵에는 바닥에서 솟았다 내려가는 승강 기둥과 결승 직전 엇갈린 기둥 2개가 있습니다. 카메라는 **선두 추적 / 전체 코스**로 바꾸며, 경기 화면은 두 글자 이름과 사진 OFF를 사용합니다. 마지막 2명이 결승 22m 안에서 4m 이내 접전을 벌이면 최대 2.5초간 약 0.65배속으로 보여준 뒤 선택한 배속으로 돌아갑니다. **핀볼**은 선수·ACE·맵 추첨과 1/2/4배속을 지원합니다. **룰렛**은 판 개수를 정하고 원판 각 칸에 입력한 뒤 설정 완료 → 돌리기 순서로 사용합니다.
5. **귀인 00**에 시청자 닉네임·TOTAL·두당·비고를 기록합니다. TOTAL과 두당 중 하나를 입력하면 나머지가 환산됩니다. 오늘 참가자와 합계도 함께 표시됩니다.
6. 경기 인원은 상단의 `5 vs 5` 같은 인원 표시를 눌러 바꿉니다. 버전은 왼쪽 아래에 표시됩니다.

5:5에서 후원 총액 1,000개는 승리팀 두당 200개입니다. 나누어떨어지지 않는 수량은 잔여 별풍선으로 따로 표시합니다. 총액 입력을 기준으로 보존하며 단순 포커스 이동으로 잔여 수량이 사라지지 않습니다.

- 변경 사항은 자동 저장됩니다. 웹 버전은 브라우저 저장소(localStorage), 설치본은 `%APPDATA%/PL SET/session-v1.json`에 저장합니다. 브라우저 데이터를 지우면 웹 세션이 사라지므로 방송 전후에 세션 내보내기로 백업하세요.
- 실행 취소 버튼 또는 입력칸 밖에서 `Ctrl+Z`로 최근 변경을 되돌립니다. 실행 취소 기록은 페이지를 닫으면 초기화됩니다.
- 우측 상단 **내보내기**는 참가자·펀딩 순위(관전 줄 포함)·팀 편성·귀인 펀딩·오늘의 진행을 정리한 메모장 파일(`1026PL.txt` 형식)을 저장합니다. JSON 백업은 상단 경기 인원 표시를 눌러 연 경기 설정의 **세션 내보내기**로 만들고 같은 곳에서 다시 불러옵니다.
- 펀딩 1위에는 왕관이 붙고, 1위와 꼴등 행에만 비고 칸이 열립니다. 꼴등 비고는 비어 있으면 **룸따개**로 표시됩니다. 펀딩 표의 **관전 복사하기**는 상위 6명의 이름을 `관전 : 홍규-정우-…` 형태로 복사합니다.
- 팀 편성은 드래그한 순서대로 슬롯이 채워지고, 처음 들어간 선수의 이름을 따 `홍규팀`처럼 팀 이름이 자동으로 정해집니다. 직접 입력한 팀 이름은 유지됩니다.
- 핀볼 맵 추첨의 맵 목록은 칩의 ×로 빼고 입력칸에 이름을 적어 Enter로 추가할 수 있습니다(2~30개). 경기 수는 맵 수를 따라갑니다. 결승 통로 위에는 구슬을 밀어내는 회전 바가 있습니다.
- **설정** 탭에서 테마 색상 8종(포레스트·미드나이트·바이올렛·버건디·골드·앰버·틸·블랙 & 화이트)을 고를 수 있습니다. 이 브라우저(설치본은 이 PC)에만 저장되며 선수 사진과 1위·경고·B팀 색은 유지됩니다.
- 타이머는 실제 마감 시각 기준으로 동작하므로 출력 창을 열거나 다른 페이지로 이동해도 시간이 유지됩니다. 실행 취소 시 타이머는 일시정지됩니다.

## Windows 설치본 (종료 예정)

PL SET은 웹 버전으로 운영하며, 설치본은 웹 버전이 안정되면 배포를 종료합니다. 설치본의 세션 내보내기 JSON은 웹 콘솔에서 그대로 불러올 수 있습니다.

`release-build/PL SET Setup 0.2.4.exe`는 Windows x64용 NSIS 설치 파일입니다. 실행 후 설치 위치를 선택하면 바탕화면과 시작 메뉴에 **PL SET** 바로가기가 만들어집니다. 최신 배포는 https://starjoa.kr/programs/plset 에서 받습니다.

설치 없이 실행하려면 `release-build/win-unpacked/PLSet.exe`를 사용합니다. 이 경우 `win-unpacked` 폴더 전체가 필요합니다.

### 설치본 자동 업데이트

- 0.1.2 설치본부터 스타조아의 정식(stable) 배포 버전을 확인합니다. 기존 0.1.0 사용자는 이번 설치본을 한 번 직접 설치해야 합니다. 검증 중 설치형 앱 판별 문제가 발견된 0.1.1은 배포 중지했습니다.
- 실행 5초 후와 실행 중 4시간마다 새 버전을 확인하고, 더 높은 버전이면 자동 다운로드합니다. 왼쪽 아래 **업데이트 확인**으로 직접 확인할 수도 있습니다.
- 설치 파일 이름이나 등록 날짜가 아니라 앱 버전과 등록된 `1.2.3` 버전을 숫자로 비교합니다. 베타·배포 중지·버전 미확인 배포는 받지 않습니다.
- 다운로드 완료 시 **설치 및 재시작**과 변경 내역을 표시합니다. 버튼을 누르고 확인해야 종료·설치가 진행됩니다. 방송 중 자동 종료하거나 강제로 설치하지 않습니다.
- 앱에 고정한 Ed25519 공개키로 배포 서명을 검증하고, 전체 파일 SHA-256과 크기를 검사합니다. 설치 직전에도 배포 상태와 로컬 파일을 다시 검사합니다. 실패하면 앱을 종료하지 않고 다시 확인할 수 있습니다.
- 설치 직전에 진행 내용을 저장하고 `session-v1.json.before-update`로 백업합니다. 기존 설치 경로에 NSIS 업데이트를 실행하며 설치 후 앱을 다시 실행합니다. 설치 없이 푼 `win-unpacked`는 먼저 설치본으로 설치해야 합니다.
- 새 배포는 package.json 버전을 올리고 `npm run dist`로 빌드한 EXE를 **동일한 버전 번호로** 스타조아 관리자에 등록합니다. 기존 버전의 파일은 교체하지 않습니다.

`electron/update-config.cjs`에는 서버 주소, 다운로드 주소로 허용하는 출처 목록(`starjoa.vercel.app`, `starjoa.kr`), 공개키만 들어갑니다. 사이트의 `SITE_URL`을 starjoa.kr로 옮겨도 0.2.0 이상 앱은 업데이트를 계속 받습니다. 관리자 비밀번호·R2 키·서명 비밀키는 앱에 포함하지 않습니다. 공개키를 바꾸면 이미 배포한 앱의 신뢰 키와 달라지므로 기존 서명 키를 유지해야 합니다.

## 선수 자료

갓·킹·잭·조커·스페이드·0티어 선수 140명과 사진 137장을 2026-10-22 기준으로 포함합니다. 선수 사진은 ASL에서 제공받았습니다. 사진이 없는 김봉실·최성원·초롱초롱은 이름으로 표시됩니다. 사진은 로컬에 보관하므로 실행 시 외부 연결이 필요하지 않습니다. 별명은 로컬 검색용 보조 정보입니다.

선수 명단은 `src/roster.json`, 사진은 `public/portraits/p001.jpg` 형식으로 보관합니다. 선수를 추가하려면 다음 번호로 사진을 넣고 `roster.json`에 항목을 추가한 뒤 다시 빌드합니다.

## 개발

Node.js 22.12 이상이 필요합니다.

```powershell
npm install
npm run dev
```

```powershell
npm test            # 금액 환산, 추첨, 팀 편성, 검색, 세션 검증
npm run test:updater # 업데이트 서명·변조·다운로드·설치 전 검사
npm run build      # TypeScript 검사와 화면 빌드
npm run build:web  # 브라우저용 빌드를 ../starjoa/public/proleague/app 에 복사
npm run pack       # Windows 실행 폴더 (설치본, 종료 예정)
npm run dist       # Windows 설치 파일 (설치본, 종료 예정)
node scripts/persistence-single-instance.cjs # 패키지의 저장·복원·중복 실행 검증
node scripts/updater-live-check.cjs # 운영 서버 확인, 설치 실행 없음
```

브라우저 검증에는 `npm run dev:web`와 Playwright CLI를 사용합니다. `scripts/browser-smoke.js`는 CLI의 `run-code --filename`으로 실행하는 수동 검증 스크립트입니다.

Windows에서 electron-builder의 압축 해제 후 폴더 이름 변경이 EPERM으로 실패하여 `pack`/`dist`는 설치된 동일 버전의 `node_modules/electron/dist`를 사용하도록 설정했습니다. 시스템 프로그램이나 실행 중인 PL SET은 변경하지 않습니다.

`node scripts/updater-native-smoke.cjs <스타조아의 .env.local 경로>`는 서명 키를 메모리에서만 읽어 비공개 테스트 응답을 만들고, 별도 임시 사용자 데이터로 패키지를 실행합니다. 자동 감지·다운로드·UI·설치 취소·저장을 검증하며 실제 설치 파일은 실행하지 않습니다. 키나 테스트 배포를 외부에 게시하지 않습니다.

## 현재 범위

펀딩은 진행자가 입력하는 수동 집계입니다. SOOP 계정 연결, 별풍선 실시간 수집, 실제 별풍선 송금·정산은 구현하지 않았습니다. 핀볼은 회전 장애물·범퍼·경사로를 지나는 물리 시뮬레이션입니다. 3초 카운트다운 후 출발하며, 선수 사진·카메라 추적·실시간 순위·전체 화면(F)을 제공합니다. 모든 순위는 실제 결승선 통과 순서로 결정됩니다.
