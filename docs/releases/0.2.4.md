레이스
- 6개 테마 코스와 긴 협곡 코스: 정글·우주·설산·도시·화산·협곡을 선택할 수 있습니다. 협곡은 긴 직선과 큰 지그재그, 회전 장벽으로 구성했습니다.
- 모든 맵에 바닥에서 올라왔다 내려가는 기둥을 추가하고, 결승선 앞에도 번갈아 움직이는 기둥 2개를 배치했습니다.
- 벽과 장애물 사이 통로를 넓혀 끼임을 줄였습니다. 정체·이탈 후에는 앞쪽으로 건너뛰지 않고 기존 진행 지점 근처의 빈 공간에서 다시 출발합니다.
- 마지막 두 명이 결승선 근처에서 접전할 때 최대 2.5초 동안 0.65배속으로 보여줍니다. 순위는 실제 결승선 통과 순서대로 결정됩니다.
- 참가 대상 선택 메뉴를 개선했습니다. 이름표는 성을 뺀 두 글자로 표시하고, 선수 사진·랜덤 맵·마지막 추적 버튼을 정리했습니다. 선두 추적과 전체 코스 보기를 지원합니다.
- 참가자별 수량 조절, 기본 1.5배속, 경주 시작 시 화면 전환과 움직임, 역전 기회를 주는 이동 장벽을 개선했습니다.
