# 진행 대시보드 참가자 패널 · 종족별/팀별 보기 전환

날짜: 2026-10-28

## 목표
진행 대시보드의 참가자 패널에서 `종족별 | 팀별` 전환 버튼을 눌러, 팀 편성 탭에서 짠 A팀/B팀 구성을 같은 자리에서 볼 수 있게 한다. 보기 전용이며 팀 배정 변경은 팀 편성 탭에서만 한다.

## 범위
- 포함: 전환 버튼, 팀별 그룹 표시, 그룹 계산 함수와 테스트.
- 제외: 팀 배정 변경(드래그, A/B 버튼), 팀 이름 수정, 세션 저장 포맷 변경, 송출 화면 변경.

## 동작
- 참가자 제목 옆에 펀딩 표와 같은 `segmented` 스타일 버튼 `종족별 | 팀별`을 둔다. 기본값은 종족별.
- 전환 상태는 세션 파일에 넣지 않고 `localStorage`(`plset.participantView`)에 기억한다. 앱을 다시 켜도 마지막 선택이 유지되며, 값이 없거나 읽기에 실패하면 종족별로 시작한다.
- 종족별: 지금과 동일(테란 / 저그 / 프로토스).
- 팀별: 두 줄을 같은 칩 스타일로 그린다. 미배정 선수는 대시보드에서 보여주지 않는다(팀 편성 탭에서 확인).
  1. A팀: 머리글에 팀 글자 `A`, 팀 편성 탭의 팀 이름(`s.teams.A`), 인원 `n / teamSize`. 선수는 `teamMembers(players,'A')` 순서(배정 순).
  2. B팀: 위와 같음.
- 두 보기 모두 X(참가 제외) 버튼은 유지되며 지금처럼 제외 시 팀 배정도 풀린다.
- 팀 편성 탭에서 배정이나 팀 이름을 바꾸면 같은 세션 상태를 읽으므로 즉시 반영된다.

## 구현
- `src/domain.ts`: 순수 함수 `participantGroups(s, view)` 추가. `view`는 `'race' | 'team'`. 반환은 `{ key, label, players, capacity? }[]` 형태. race 보기는 T/Z/P 순, team 보기는 A/B 순이며 `capacity = s.teamSize`.
- `src/domain.test.ts`: 두 보기의 그룹 순서, 인원 집계, 비활성 선수 제외, 미배정 집계를 검증하는 테스트 추가.
- `src/ParticipantRoster.tsx`: `view` 상태와 전환 버튼 추가. 초기값은 `localStorage`에서 읽고(try/catch, 유효한 값만 인정), 전환 시 저장한다. 본문의 `RACES.map(...)`을 `participantGroups(s, view).map(...)`으로 바꾼다. 머리글 마크는 race 보기면 `RaceMark`, team 보기면 팀 글자(`A`/`B`) 또는 미배정 아이콘 없는 텍스트.
- CSS(`src/race-entry.css`): `.race-entry-A`, `.race-entry-B` 칩 색상을 기존 `.team-A`/`.team-B` 색 계열로 맞추고, 머리글 팀 글자는 기존 `.race` 박스 크기와 같은 작은 박스로 그린다. 레이아웃(줄 높이, 그리드)은 바꾸지 않는다.

## 검증
- `npm test`로 domain 테스트 통과.
- `npm run build`로 타입 검사 통과.
- `npm run dev`로 실행해 전환 버튼으로 두 보기를 오가고, 팀 편성 탭에서 배정을 바꾼 뒤 대시보드에 반영되는지 확인.
